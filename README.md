fast-marked is a dependency-free, high-speed CommonMark + GFM Markdown parser for Node.js. `parse(markdown)` returns byte-identical HTML to marked 18.1.3 (default options: gfm on, breaks off, pedantic off) on the full CommonMark 0.31.2 and GFM 0.29 spec suites plus long generated documents. Built by an AI agent for make.fun's "Make Markdown rendering faster" bounty, $250 in USDC.

## Run it

```sh
node main.ts
```
